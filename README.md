# 🛒 Supermarket Sales Analysis

## 📌 Overview
This project analyses supermarket sales data to understand revenue trends, product performance, and customer buying behaviour, and to turn them into insights a store manager could act on.
## 🛠️ Tools Used
Python (Pandas, Matplotlib, Seaborn)
## ❓ Business Questions
- Which product categories generate the most revenue and profit?
- What are the peak sales year/month?
- How do sales differ across branches and customer types?
- Which payment methods do customers prefer?
